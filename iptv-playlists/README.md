# BOMBALA IPTV

PHP/MySQL-проект каталога IPTV-плейлистов с серверной админ-панелью.

## Установка

1. Загрузите папку `iptv-playlists` на PHP-хостинг и настройте веб-корень на неё.
2. Убедитесь, что у пользователя MySQL есть доступ к базе `bombalamoy`.
3. Откройте в браузере `install.php` один раз — он создаст таблицы и стартовые данные.
4. Удалите `install.php` с хостинга после успешной установки.

## Данные подключения

Подключение MySQL настроено в `config.php`: сервер `localhost`, база `bombalamoy`, пользователь `bombalamoy_usr`.

## Админ-панель

Откройте `admin.php`. Пароль администратора в базе хранится в виде криптографического хеша и проверяется серверной функцией `password_verify`, а не в JavaScript. Через панель можно добавлять и удалять плейлисты.
