# BOMBALA IPTV

PHP/MySQL-проект каталога IPTV-плейлистов с регистрацией, закрытым доступом к M3U-ссылкам и серверной админ-панелью.

## Установка

1. Загрузите папку `iptv-playlists` на PHP-хостинг и настройте веб-корень на неё.
2. Убедитесь, что у пользователя MySQL есть доступ к базе `bombalamoy`.
3. Поместите оригинальный логотип в `assets/bombala-logo.png`. Смотрите `assets/README.md`.
4. Откройте в браузере `install.php` один раз — он создаст таблицы и стартовые данные.
5. Удалите `install.php` с хостинга после успешной установки.

## Данные подключения

Подключение MySQL настроено в `config.php`: сервер `localhost`, база `bombalamoy`, пользователь `bombalamoy_usr`.

## Админ-панель

Вход и регистрация находятся в `auth.php`. Пароль хранится в базе в виде криптографического хеша и проверяется серверной функцией `password_verify`.

Откройте `admin.php` после входа администратором. В панели можно создавать, изменять и удалять категории, а также создавать, редактировать, скрывать и удалять плейлисты. Ссылка M3U показывается только авторизованному пользователю на странице `playlist.php`.
